{{- /* 記事のプレーンテキスト要約。front matter の description を優先し、無ければ .Summary （ まで、または summaryLength 分の HTML）から見出し（アンカーの # を含む）を 丸ごと落とし、残りのタグを空白に置き換えて（隣接ブロックの語が連結しないよう）空白を畳む。記事一覧・検索索引・seo.html で共有し、 長さの切り詰めは呼び出し側で行う。 */ -}} {{- $s := .Description -}} {{- if not $s }}{{ $s = .Summary | replaceRE `(?s)]*>.*?` " " | replaceRE `<[^>]*>` " " | htmlUnescape | replaceRE `\s+` " " | strings.TrimSpace }}{{ end -}} {{- return $s -}}
